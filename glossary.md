# Glossary

This glossary defines common terms used in execution model discussions.

## Atomic
A property where all operations in a transaction succeed together or fail together.

## Execution Context
The environment in which contract code runs during a transaction.

## Call Stack
The structured order of nested function calls during execution.

## Reversion
The process of undoing all state changes if a transaction fails.

## State
Persistent data stored on the blockchain by smart contracts.
